# 虚构样例说明（人物与 ID 均为虚构，仅用于演示）

本文件包含 4 个队列、15 条入组记录，用于演示人工关联裁决。
记录以「队列 + 来源ID」共同标识，化名中的同音错字、繁简/备注差异是随访数据中
常见的匹配线索，但系统本身不做自动匹配，全部关系由人工裁决产生。

## 分组约束提醒

- 每个分组内，同一队列最多一条记录；
- 判为 different 的两条记录永远不得落入同一分组；
- 任何违反约束的裁决**整次拒绝**，数据库保持提交前状态。
